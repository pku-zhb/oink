# Oink — Oink Is Not only a KVM

> **这是 pku-zhb 基于 Oink v0.3.2 修改的实验性 fork，并非官方发行版。**
> 保留原项目署名与许可；本分支新增“物理屏幕归属”功能。

## 物理屏幕归属（本 fork 新增）

在“设置 → 布局 → 物理屏幕归属”中，使用向导确认物理位置、每台电脑对应的系统屏幕和视频输入口。配置会共享给参与电脑；两屏两电脑提供四种布局卡片，也可逐屏选择电脑，不必枚举所有组合。

1. 两端安装此分支的新版本并保持在线，开始“设置共用显示器”。可导入旧版绑定；已有映射只有在用户明确确认经过日常验证后才直接采用。
2. 按真实的左右位置排列屏幕。逐块、逐输入测试：后台临时切换，显示目标电脑标识，约十秒后自动恢复，再由用户确认关系。未知控制码不会被自动轮询；特殊显示器可在高级设置中填写已知值。
3. 保存后选择布局。兼容模式保留系统扩展桌面；完整模式还会停用不可见的系统显示器并选择可见主屏。Windows 使用会话范围的原生 CCD 接口；Mac 需要支持连接管理的 BetterDisplay 和相应 Pro 功能。
4. 布局应用后有十五秒保留／恢复确认，可从任一可见参与端操作。未确认会恢复上一配置；独立进程负责未完成操作的超时恢复，设置页关闭不取消保护。
5. “恢复切换前配置”恢复进入物理模式前保存的输入、系统桌面、主屏和 Oink 路由。协调电脑离线时可先恢复本机；此操作不代表另一端也已恢复。

完整模式在写输入前检查是否会移除最后一块物理屏。11 或 22 使某台电脑没有可见外接屏时，若没有其他物理屏可保留，请使用兼容模式；不会用虚拟显示器绕过该保护。未纳入配置的内屏、外接屏和虚拟屏不作为本功能的停用目标。

显示器是否支持 DDC、切源后是否仍可控制、软件断开后能否重新接入，都依赖实际硬件。无法读回输入的显示器使用已确认的映射，界面不会把命令成功当成硬件确认。兼容模式仍可能让窗口出现在不可见桌面；原生停屏与应用窗口行为需要实机验收。

当前开发包含模拟双机事务和恢复测试。系统适配器的编译或模拟测试通过，不等于任意硬件已经验收。发生黑屏或显卡驱动超时，应停止连续切换并保留系统事件和崩溃转储；不要通过修改 TDR 注册表项掩盖问题。

开发者接口、预览和实现边界见 [物理屏幕开发说明](docs/physical-monitors.md)。产品目标见 [PRD](docs/physical-monitor-prd.zh-CN.md)。旧版 `query/save/read/test/apply/clear` 接口保留用于迁移；新界面使用版本二流程。

Oink 是 Oink Is Not only a KVM 的缩写，是一款在多台 Windows 和 Mac 设备间建立对等共享网络的现代软件。同时使用任何设备的键盘、鼠标、触摸板操控任意邻近设备，保持统一、原生的操作手感；将多台设备的音频通过连接至一台设备的扬声器或耳机播放；支持剪贴板共享和跨设备拖拽；支持局域网设备自动发现；默认加密传输。

## 安装

从 [GitHub Releases](https://github.com/oinkvm/oink/releases) 下载安装包和对应的源码。

支持的操作系统和版本：

- **Mac**：仅支持 Apple 芯片（arm64），macOS 14.2 及以上
- **Windows**：x64，Windows 10 22H2（build 19045）及以上，或 Windows 11

如果 SmartScreen 提示“Windows 已保护你的电脑”，仅在出现相应选项时点击 **更多信息 → 仍要运行**。UAC 可能显示发布者未知。

## 常见问题

**Oink 是基于 Deskflow 或兼容 Deskflow 的吗？**\
不是。Oink 是完全从零开始的项目，使用自研的对等（非客户端-服务端）协议，不兼容其他软件 KVM。

**必须指定一台设备为控制端吗？**\
不必须。Oink 采用对等网络设计，连接在任何设备上的键鼠都可以用来控制其他设备。

**支持共享触摸板手势吗？**\
支持，但 Windows 触摸板未经过测试。

**支持跨操作系统的剪贴板共享和跨设备拖拽吗？**\
支持。剪贴板会在设备间自动同步，也可以直接将文字、图片、文件从一台设备拖拽到另一台设备，甚至直接拖进 Chrome 等应用内。

**个人或商业使用 Oink 需要购买许可吗？**\
不需要。Oink 是以 GPL-3.0-only（附带附加条款）发布的自由软件，可以用于任何个人或商业用途，无需申请额外许可。如果分发 Oink 或基于它修改的版本，必须以同一许可证提供完整源码，保留原作者署名和许可声明，并标明所做的修改；按附加条款，也不得以 Oink 的名义推广衍生产品。仅供自己使用的修改、不对外分发时，没有这些义务。
