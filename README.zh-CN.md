# Oink — Oink Is Not only a KVM

> **这是 pku-zhb 基于 Oink v0.3.2 修改的实验性 fork，并非官方发行版。**
> 保留原项目署名与许可；本分支新增“物理屏幕归属”功能。

## 物理屏幕归属（本 fork 新增）

两台电脑共用两块显示器时，系统可能把同一块物理显示器的两个输入连接识别成两块逻辑屏幕。本功能把这些身份绑定到同一块物理屏幕，并在切换输入源时同步鼠标路由。两块屏、两台电脑会生成四种组合。

在“设置 → 布局 → 物理屏幕归属”中：

1. 先让两台电脑都检测到两块显示器，开启屏幕与键鼠共享，并解锁指针焦点。两台电脑都需要运行此 fork；Mac 控制端需要 BetterDisplay，Windows 控制端使用系统原生 DDC。希望在哪台电脑上点击组合，就在那台电脑上分别保存绑定。
2. 点击“识别屏幕”。按实际从左到右的顺序添加两块物理屏幕，分别匹配它们在 Mac 和 Windows 上的逻辑身份。控制端使用精确的系统显示器身份（Mac UUID / Windows 设备路径）定位显示器，不按相似名称猜测。
3. 记录各电脑对应的输入源数值。可以手动切换显示器输入后点击“读取当前输入”，也可以填入已经验证过的十进制或十六进制值。常见标准值并不保证适合所有显示器，不会自动轮询未知值。
4. 用“测试并恢复”确认选中的电脑是否出现；后台会在测试后恢复原输入源。保存绑定后，点击所需的左右屏组合即可切换。

切换前会检查绑定、连接和两端功能支持，并读取原输入值。后台依次切换显示器并读回确认，全部确认后才发布新的物理屏幕布局；失败时尝试恢复原输入源，并明确报告恢复失败。DDC 读回只验证显示器报告的值，首次绑定仍需目视确认电脑与端口的对应关系。

物理模式只让选中的逻辑身份参与路由。未选中的副本不会遮挡跨屏路径；焦点落在已不可见的屏幕时会迁移到可见屏幕。没有可见屏幕的电脑仍可作为键鼠输入来源。点击“返回普通布局”恢复原来的路由几何；此操作不会切换显示器输入源。

目前采用从左到右的水平物理布局，DDC 发令支持 Mac + BetterDisplay，以及 Windows 原生接口。显示器必须允许控制端在输入切走后继续读写 DDC，否则程序会报告失败，不能承诺在该硬件上完成全部四种组合。系统扩展桌面保持启用，窗口仍可能在当前不可见的逻辑屏幕上打开；本功能不负责系统显示器的启用、停用或窗口搬迁。

也可通过已有命令行接口调用，例如只读查询：

```sh
oink-agent call physical_monitors '{"command":{"action":"query"}}'
```

支持 `query`、`save`、`read`、`test`、`apply`、`clear` 操作；`apply` 使用保存时的配置版本及按物理顺序排列的屏幕身份，可以接入已有快捷指令。绑定保存在控制端应用数据目录的 `physical-monitors.json` 中，组内共享的是当前路由归属。

Oink 是 Oink Is Not only a KVM 的缩写，是一款在多台 Windows 和 Mac 设备间建立对等共享网络的现代软件。同时使用任何设备的键盘、鼠标、触摸板操控任意邻近设备，保持统一、原生的操作手感；将多台设备的音频通过连接至一台设备的扬声器或耳机播放；支持剪贴板共享和跨设备拖拽；支持局域网设备自动发现；默认加密传输。

## 安装

从 [GitHub Releases](https://github.com/oinkvm/oink/releases) 下载安装包和对应的源码。

支持的操作系统和版本：

- **Mac**：仅支持 Apple 芯片（arm64），macOS 14.2 及以上
- **Windows**：x64，Windows 10 22H2（build 19045）及以上，或 Windows 11

如果 SmartScreen 提示“Windows 已保护你的电脑”，仅在出现相应选项时点击 **更多信息 → 仍要运行**。UAC 可能显示发布者未知。

## 常见问题

**Oink 是基于 Deskflow 或兼容 Deskflow 的吗？**\
不是。Oink 是完全从零开始的项目，使用自研的对等（非客户端-服务端）协议，不兼容其他软件 KVM。

**必须指定一台设备为控制端吗？**\
不必须。Oink 采用对等网络设计，连接在任何设备上的键鼠都可以用来控制其他设备。

**支持共享触摸板手势吗？**\
支持，但 Windows 触摸板未经过测试。

**支持跨操作系统的剪贴板共享和跨设备拖拽吗？**\
支持。剪贴板会在设备间自动同步，也可以直接将文字、图片、文件从一台设备拖拽到另一台设备，甚至直接拖进 Chrome 等应用内。

**个人或商业使用 Oink 需要购买许可吗？**\
不需要。Oink 是以 GPL-3.0-only（附带附加条款）发布的自由软件，可以用于任何个人或商业用途，无需申请额外许可。如果分发 Oink 或基于它修改的版本，必须以同一许可证提供完整源码，保留原作者署名和许可声明，并标明所做的修改；按附加条款，也不得以 Oink 的名义推广衍生产品。仅供自己使用的修改、不对外分发时，没有这些义务。
